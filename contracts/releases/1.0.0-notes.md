# Platform release 1.0.0

This release publishes the immutable compatibility package and release-manifest
validation contract.

- Security impact: references, source, qualification evidence, and provider
  locks must be checksum-bound; no long-lived workload credentials are used.
- Compatibility: consumers must use the supported component and schema ranges
  in the manifest and pin provider lock checksums.
- State/address changes: none; consumer migration is a separate two-phase
  story.
- Rollback identity: revert to the prior immutable GitHub release/tag and
  retain both release manifests for the 30-day rollback horizon.
- Limitations: managed-runtime exceptions and dated qualification observations
  are recorded in the manifest; live AWS qualification remains evidence-bound.
- Stories 3.8/3.9: migration and deprecation do not apply to this release.

The GitHub release and the internal engineering channel are the approved
publication notices. A defective release is marked affected and corrected with
a new version; neither the original artifact nor its evidence is overwritten.
